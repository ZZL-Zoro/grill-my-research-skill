# 方法背景与使用边界

本 skill 的提问路由、六轮检查点、状态标签和交付模板是为对话组织设计的工作约定，
不是经过验证的科研质量量表，也不声称来自以下文献。这里仅记录影响关键回答的
少量方法依据；实际课题仍需其领域方法和直接证据。

## 探索与验证分开标记

研究问题可以来自探索；后续验证时须诚实交代假设形成于什么时候、哪些分析事先
计划、哪些来自看到数据后的调整。必要时讨论独立数据或下一轮验证，不把所有项目
都强制变成预注册实验。参考 [Center for Open Science：Preregistration](https://www.cos.io/initiatives/prereg)。

这里采用的是透明区分的原则；本 skill 不自动注册计划，不替用户虚构事前时间线。

## 不显著不自动等于没有有意义效应

阴性结果的解释取决于设计、精度、要排除的效应范围和相应分析。需要检验实质等效
时，界限必须有科学理由，不能看完结果临时设置成方便通过的数值。参考
[Lakens, 2017：Equivalence Tests: A Practical Primer](https://pubmed.ncbi.nlm.nih.gov/28736600/)。

该来源讨论特定定量框架，不是要求定性或理论研究采用相同统计标准。没有足够信息
时，本 skill 应保留“信息不足”，而非自动给出样本量、功效或效应界值。

## 论证工具的能力范围

竞争解释、可区分预测、反例、测量边界和结果决策是本项目采用的组织方式。工具
可以帮助发现断裂和提出取证路径，不能保证文献检索完整、科学结论正确、方案可获批
或研究能发表。不要将语言上的连贯性当成独立证据。
