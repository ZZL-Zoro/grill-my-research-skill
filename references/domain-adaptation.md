# 按研究类型改变证据问题

这是路由示例，不是学科标准的完整目录。混合研究可能需要多个部分；只选对当前主张有用的内容，不能让所有课题都走生物实验的因果链。

| 类型 | 优先区分什么 | 常见关键追问 | 不应强加什么 |
|---|---|---|---|
| 实验／机制 | 干预效应、特异性、竞争路径与直接机制 | 哪个结果会区分目标过程与最相关替代解释？ | 把一次干预或救援自动等同直接机制 |
| 观察／关联 | 构念、测量、混杂、选择与时间顺序 | 在可接受假设下，当前设计能支持关系还是因果？ | 为没有干预的设计承诺因果证明 |
| 计算／机器学习 | 任务定义、基线、泄漏、评估与外推 | 这种提升在怎样的数据划分和部署条件下仍成立？ | 把预测提升等同机制发现，或默认复杂模型更好 |
| 方法／工程 | 使用场景、约束、性能目标和失效条件 | 与适当基线相比，哪种权衡变化才有实际意义？ | 给没有资源信息的项目编造成本或工期 |
| 理论／数学 | 定义、公理、命题、边界、证明与反例 | 哪个条件是命题成立不可去掉的？ | 一律要求样本量、p 值或湿实验 |
| 质性／解释性研究 | 研究立场、材料选择、分析过程与反例 | 哪类材料会迫使你修改当前解释？ | 把所有质量问题归结为统计功效或随机分组 |
| 描述／探索／资源型研究 | 覆盖、代表性、测量可靠性和可复用贡献 | 你希望描绘的未知结构是什么，怎样知道描绘有遗漏？ | 为了显得严谨强造单一因果假设 |
| 复现／阴性研究 | 目标主张、关键条件、精度及证据可比性 | 什么结果能区分有意义的差异与信息不足？ | 因“不是首创”就预先判无价值 |

不熟悉的细分领域先确认其主张和证据习惯；专业技术事实需核查来源。结构性判断可以先作，但把领域假设显式列出。该表不替代领域专家或具体方法文献。
